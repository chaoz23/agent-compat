# Calibration

**Phase 2 — not yet built.** Stub on purpose.

This directory will hold the retrodiction harness (PRD R8): given twin pairs of *known-outcome* real relationships (consented research data or synthetic gold sets), measure whether stress-scenario simulation predicts outcomes better than a profile-similarity baseline. A rigorous null result counts — it still establishes this framework as the venue for the question.

Ground-truth data acquisition has the longest lead time in the project. If you have access to consented known-outcome pairing data (cofounder retention at 12 months, working-relationship quality at 90 days), open an issue now, in Phase 0/1 — don't wait for this harness to exist.
