# Decisions

Architecture Decision Records. One file per decision, numbered, never deleted — superseded ADRs get `Status: SUPERSEDED by ADR-NNNN`.

Format per ADR:

```
# ADR-NNNN: Title (as a question where possible)
**Status:** OPEN | ACCEPTED | REJECTED | SUPERSEDED by ADR-NNNN
**Deciders:** who
**Date opened / decided:**

## Question
## Positions (all of them, including the losing ones)
## Decision
## Consequences
```
